# 野球部成績管理アプリ

中学校野球部の成績を、1球ごとに記録して自動集計するWebアプリです。
iPhone（試合中の入力）と学校PC（ChromeやEdgeでの確認）で使えます。

- アプリのアドレス：https://6p5ts2kb5b-cyber.github.io/baseball-stats/
- お試しモード（見本データ・保存されません）：https://6p5ts2kb5b-cyber.github.io/baseball-stats/?demo

## 使い方の流れ
1. 「設定」で選手を登録する（表示名・背番号・投打）
2. 「試合」→「新しい試合」で相手・大会区分・スタメンを入れる
3. 入力画面で1球ずつボタンを押す（四球・三振・死球は自動で打席終了）
4. 「打った！」を押したら結果を選び、「確定」
5. 試合が終わったら「走者・その他」→「試合終了にする」
6. 「打者成績」「投手成績」で通算・直近の試合・大会別・試合別・月別・相手別に確認
7. 「印刷」で個人成績レポート（1人ずつ／全員）、試合の画面の「印刷」で試合レポートをA4で印刷（PDF保存も可）
8. 試合レポートの「共有する」で、画像・PDF・テキストをLINEなどで保護者に送れる（印刷と同じ内容）

## iPhoneでアプリのように使う
Safariでアドレスを開き、共有ボタン →「ホーム画面に追加」。
ホーム画面から開いた場合は、メールアドレスでのログインがおすすめです。

## 圏外での入力
一度電波のある場所でログインして試合画面を開いておけば、圏外でも入力できます。
入力は端末に保存され、電波が戻ると自動で送られます（画面上部に「圏外：端末に保存中」と出ます）。

## ファイルの役割（修正するとき用）
| ファイル | 役割 |
|---|---|
| `js/stats.js` | 打率・OPS・QSなどの計算。計算方法を変えるときはここだけ |
| `js/store.js` | Firebaseへの保存・読み込み・ログイン |
| `js/views/input.js` | 試合中の1球入力画面 |
| `js/views/game.js` | 試合の記録（スコア表・投手成績・打席の修正） |
| `js/views/statsview.js` | 打者成績・投手成績・選手ページ |
| `js/views/print.js` | 印刷（個人成績レポート・試合レポート） |
| `js/share.js` | 共有（印刷画面を画像・PDFにする、スマホの共有メニュー） |
| `js/views/settings.js` | 設定（選手・大会区分・集計ルール・使える人・バックアップ） |
| `js/firebase-config.js` | Firebaseの接続設定・持ち主のメールアドレス |
| `firestore.rules` | データの鍵（Firebaseの「ルール」に貼り付けるもの） |
| `sw.js` | 圏外でも開けるようにする仕組み（更新時は VERSION を上げる） |
| `docs/設計書.md` | 設計書 |

計算のテスト：`node tests/stats.test.mjs`

## チーム独自の集計ルール
- 打数に含めない：四球・死球・犠打・犠飛・進塁打
- 出塁率＝（安打＋四球＋死球）÷（打数＋四球＋死球＋犠飛）… 進塁打は分母に入れない
- 奪三振率・防御率は7イニング換算
- QS：先発で5回以上・自責点2以下
（すべて「設定 → 集計ルール」で変更可）
