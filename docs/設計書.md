# 野球成績管理アプリ 設計書（確定版 v1.0 / 2026-09-29）

## 1. 構成
| 役割 | 使うもの | 費用 |
|---|---|---|
| アプリ本体の保管・公開 | GitHub ＋ GitHub Pages | 無料 |
| データ保存・同期・オフライン | Firebase Cloud Firestore（Sparkプラン） | 無料 |
| ログイン | Firebase Authentication | 無料 |
| グラフ | Chart.js（CDN） | 無料 |
| Excel出力 | SheetJS（CDN） | 無料 |
| PDF | ブラウザ印刷 →「PDFに保存」（A4専用レイアウト） | 無料 |

- 素のHTML / CSS / JavaScript のみ。ビルドツールなし（ブラウザだけで修正可能）。
- iPhoneは「ホーム画面に追加」でPWAとして使用。
- 選手データはGitHubには置かない（Firebaseのみ）。

## 3. データベース（Firestore）
```
team/settings              集計ルール表、大会区分(ID付き)、イニング数(7)、QS基準
members/{uid}              ログイン許可と権限（admin / scorer / viewer）
players/{playerId}         表示名、入学年度、投(R/L)、打(R/L/S)、主守備、背番号{年度:番号}、在籍状態
games/{gameId}             年度、通し番号、日付、相手、大会区分ID、先攻/後攻、得点、勝敗、状態、
                           スタメン、相手打順の左右、投手別成績(先発,投球回,失点,自責点,QS)、選手別サマリー
games/{gameId}/halves/{回+表裏}   その半イニングの全打席・全投球
games/{gameId}/events      打席外の出来事（走者生還、盗塁、牽制刺、失策 など）
changeLog/{id}             変更履歴（いつ・誰が・何を）
trash/{id}                 削除データ（30日間復元可）
```
- 学年は入学年度から自動計算。背番号は年度別。引退選手もデータは残す。
- 大会区分はIDで管理（名称変更しても過去データが崩れない）。
- 1球＝1ドキュメントにはしない（読み取り回数対策）。半イニング単位＋試合サマリー。

## 4. 打席データ
```
{ paNo, inning, half:"top|bottom", offense:"us|them",
  batter(選手ID or 相手打順), batterHand, pitcher(選手ID or 相手投手名), pitcherHand,
  outsBefore, runners:[1,2,3のうち], // 得点圏は2塁or3塁で自動判定
  pitches:[{r:"B|S|K|F|X|D"}],        // B=ボール S=見逃し K=空振り F=ファウル X=打球 D=死球
  result, rbi, runs, earnedRuns, outsMade, responsiblePitcher }
```
- カウントは投球列から自動計算。打撃結果の確定＝打席終了。
- スイング判定（K/F/X）を保持 → 初球スイング率・見逃し率に拡張可能。

## 5. 集計ルール（確定）
打数に含めない：四球・死球・犠打・**犠飛**・**進塁打**（チーム独自ルール）
打数に含める：安打・凡打・三振・併殺・**失策出塁**・**野選**
※設定画面の「集計ルール表」で変更可。変更すると全試合を再計算。

| 指標 | 式 |
|---|---|
| 打数 | 打席 −（四球＋死球＋犠打＋犠飛＋進塁打） |
| 打率 | 安打 ÷ 打数 |
| 出塁率 | （安打＋四球＋死球）÷（打数＋四球＋死球＋犠飛）※進塁打は分母に入れない |
| 長打率 | 塁打 ÷ 打数 |
| OPS | 出塁率 ＋ 長打率 |
| 得点圏打率 | 2塁or3塁に走者がいた打席の 安打÷打数 |
| 初球打率 | 1球目で終わった打席の 安打÷打数 |
| 追い込まれてから | 2ストライクに到達した打席の 安打÷打数、三振÷打席 |
| カウント別打率 | 最後の1球の直前カウント（12通り） |
| 盗塁成功率 | 盗塁 ÷（盗塁＋盗塁死） |
| 初球ストライク率 | 1球目がボール・死球以外 ÷ 対戦打者 |
| 奪三振率 | 奪三振 × 7 ÷ 投球回（7イニング換算） |
| 被打率 | 被安打 ÷ 被打数 |
| 投球回 | 各打席の増加アウト数の合計 ÷ 3 |

## 6. クオリティースタート（QS）
- 基準：**先発で5回以上・自責点2以下**（設定で変更可）
- 試合ごとに投手成績欄とスコア表に「QS ○／×」を表示。印刷にも表示。
- 通算：QS数、QS率（QS ÷ 先発試合数）。
- 入力：打撃結果の後に「入った点 0〜4」、点が入ったときのみ自責/非自責トグル（既定＝自責）。打席外の得点は「走者生還」ボタン。打点の既定値＝入った点。

## 7. iPhone 1球入力
- 1球＝1タップ：ボール／見逃し／空振り／ファウル／打った！／死球
- 4ボール・3ストライク・死球は結果まで自動確定。
- 「打った！」→ 結果ボタン一覧 → 打点・得点。
- 3アウトで自動攻守交代。打順自動送り。相手打者の左右は打順ごとに記憶。
- 走者は塁ダイヤをタップ、前打席から引き継ぎ。
- 「1球戻す」無制限、直前打席の修正。
- Firestoreのオフライン保存（試合前に一度オンラインで開く）。

## 8. セキュリティ・バックアップ
- ログイン必須。Firestoreセキュリティルールで members 登録者のみ読み書き。
- 権限：管理者／入力者／閲覧者。
- 保存するのは表示名・入学年度・投打・守備位置のみ（本名・生年月日・連絡先の欄は作らない）。
- 削除はゴミ箱（30日）、確定試合の修正は確認画面、変更履歴を記録。
- 全データJSONバックアップ・復元、CSV／Excel書き出し。月1回の保存を推奨。
